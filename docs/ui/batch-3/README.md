# Component adaptations, batch 3

The supplied vertical and horizontal Tooltip Navbar patterns inform the shared
DashboardNavigation: vertical desktop controls, horizontal mobile controls,
animated hover/focus tooltips, actual routes and selected state. Labels remain
visible so touch users can navigate. Unimplemented keyboard shortcut badges from
the samples are omitted.

Show QR is adapted in the Find a party dialog, for secondary sharing of active
parties. Main party invitations and Display keep their immediately visible QR.
Semantic buttons, existing validated QR rendering, and confirmed clipboard success
replace the demo clickable divs and unchecked copying.

Alert Message provides actionable Spotify and cover feedback. Disabled Button's
ban indicator is applied to genuinely unavailable idle actions. Display Card and
Button Group form the Party Archive cards and their real playlist/details actions.
The gallery uses user covers and actual dates/song counts, without demo images.
Cards float slightly on hover; Motion respects reduced-motion preferences.
All colors use the existing #111111 / black / #65b32e theme. No playback controls
or demo actions are added. Existing shared loading animations are preserved.
